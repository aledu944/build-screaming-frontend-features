# build-screaming-frontend-features

Skill para crear, extender, refactorizar y revisar frontends React + TypeScript con Screaming Architecture (TanStack Start y Next.js App Router).

## Instalación

```bash
npx skills add aledu944/build-screaming-frontend-features -g -y
```

Instalar siempre desde el repositorio de GitHub: la skill depende de `references/` y `agents/`, y deben copiarse junto con `SKILL.md`.

> No publicar en skills.sh pegando solo el contenido de `SKILL.md`. Esa publicación queda con `files: ["SKILL.md"]` y las referencias devuelven 404, por lo que la skill funciona a medias.

## Estructura

```
SKILL.md
agents/openai.yaml
references/
  architecture.md
  feature-blueprint.md
  forms.md
  nextjs-app-router.md
  shared-ui-layouts.md
  tanstack-start.md
```
